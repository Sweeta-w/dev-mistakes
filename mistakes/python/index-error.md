## 📌 Problem Overview
accessed value like if element is on position 3 so I tried to access it by 3

## ✅ Solution & Prevention
always accessed by position - 1 like in this scenario would be 2

## 💻 Code Example
```python
a = [1, 2, 3]
a[2] #3
```
